🩺 Comprehensive Machine Learning Full Pipeline on Heart Disease (UCI Dataset)

📌 General Description

This project analyzes, predicts, and visualizes heart disease risks using the UCI Heart Disease dataset.
The workflow covers the entire ML pipeline from data preprocessing to deployment with a simple Streamlit UI.

🚀 Project Workflow

1-Data Preprocessing

  -Handling missing values

  -Encoding categorical features

  -Normalization & scaling

2-Feature Engineering

  -Feature selection

  -Dimensionality reduction with PCA

3-Modeling

-Classification Models:

  -Logistic Regression

  -Decision Tree

  -Random Forest

  -Support Vector Machine (SVM)

-Unsupervised Models:

  -K-Means Clustering

  -Hierarchical Clustering

4-Evaluation

  -Accuracy, Precision, Recall, F1-score

  -ROC–AUC curves and confusion matrices

5-Deployment

  -Interactive Streamlit UI for predictions

  -Exposed via Ngrok
